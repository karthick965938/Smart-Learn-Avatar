Question: What is Machine Learning?
Answer: Machine Learning (ML) is a branch of Artificial Intelligence that enables computers to learn patterns from data and use those patterns to make predictions, classifications, or decisions without requiring explicit rules for every situation.

Question: What is supervised learning?
Answer: Supervised learning is a type of Machine Learning in which a model learns from labeled training data. Each training example contains input data and a known target or output that the model learns to predict.

Question: What is unsupervised learning?
Answer: Unsupervised learning is a type of Machine Learning in which a model analyzes data without predefined labels or target answers. The model can discover patterns, relationships, groups, or other structures within the data.

Question: What is a dataset?
Answer: A dataset is a structured collection of data used for tasks such as training, validating, testing, or evaluating a Machine Learning model. A dataset may contain features, labels, or both, depending on the Machine Learning task.

Question: What is a feature?
Answer: A feature is an individual measurable property, attribute, or characteristic of an example that is provided as input to a Machine Learning model. For example, when predicting house prices, features might include the house size, number of bedrooms, and location.

Question: What is a label?
Answer: A label is the known target value or expected output associated with a training example. Labels are commonly used in supervised learning, where a model learns to predict the label from the input features.

Question: What is classification?
Answer: Classification is a Machine Learning task in which a model assigns an input to one or more predefined categories or classes. Examples include classifying an email as spam or not spam and identifying whether an image contains a cat or a dog.

Question: What is regression?
Answer: Regression is a Machine Learning task in which a model predicts a continuous numerical value. Examples include predicting house prices, temperature, sales revenue, or delivery time.

Question: What is model training?
Answer: Model training is the process of using training data to adjust a Machine Learning model so that it learns useful patterns and relationships between inputs and expected outputs. The trained model can then be evaluated and used to make predictions on new data.

Question: What is overfitting?
Answer: Overfitting occurs when a Machine Learning model learns the training data too closely, including patterns that do not generalize well to new data. As a result, the model may perform very well on training data but poorly on unseen data.
